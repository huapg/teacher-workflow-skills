# 工作流路由规则

## 一、阶段与环节判定

把教师的一句请求映射到 A1–A10。按「命中关键词 → 落环节」判定；命中多个时，按教学时序（教前→教中→教后）取最先该发生的环节。

| 关键词信号 | 判定环节 |
| --- | --- |
| 学情、摸底、诊断、学生什么水平、入学评估、薄弱点 | A1 学情诊断 |
| 备课、教案、教学设计、这堂课怎么上、目标与重难点 | A2 备课 |
| 出题、变式、组卷、命题、分层作业、练习题 | A3 变式出题 |
| 讲义、板书、课件文案、课堂材料、例题 | A4 课堂讲义 |
| 答疑、学生问、这道题怎么做、实时解答 | A5 实时答疑 |
| 批改、判分、评分、作业对错、评语、成绩 | A6 作业批改 |
| 错题、为什么错、归因、订正、错因 | A7 错题归因 |
| 计算训练、口算、笔算、专项练习、刷题 | A8 计算训练 |
| 学习规划、学习计划、进度安排、长期目标 | A9 学习规划 |
| 家长反馈、家校沟通、家长会、给家长的 | A10 家长反馈 |

## 二、跨环节衔接（默认顺序）

- **开学/新学生**：A1 → A2 → A4（先诊断，再备课/讲义）。
- **随堂**：A5 答疑为主；学生卡壳 → A7 归因 → A8 训练。
- **作业闭环**：A6 批改 → A7 归因 → A3/A8 变式训练 → A9 规划沉淀 → A10 反馈给家长。
- **周期性**：A9 学习规划按月滚动，A1 学情诊断按周/月复检，更新画像。

## 三、模糊请求的处理

1. 能定位到唯一环节 → 直接执行。
2. 能定位到多个且时序清晰 → 按时序执行并提示衔接。
3. 完全模糊（如"帮我看看这个学生"）→ 先读画像；无画像则引导 A1 诊断，并把判定依据告诉教师，让教师确认。
