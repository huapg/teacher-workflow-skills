# 出题与变式规范（全学科通用，数学示范）

A3 变式出题、A8 计算训练、A6 批改评分共用此规范。数学先作为示范口径，其他学科按同一骨架扩展。

## 一、通用出题流程

1. **明确输入**：知识点 / 原题 / 年级与学段 / 目标（诊断、巩固、拔高、考试）。
2. **定难度分层**：L1 基础（概念直接应用）→ L2 常规（标准题型）→ L3 变式（改条件/换情境）→ L4 综合（多知识点结合）。
3. **选题型**：单选、多选、判断、填空、简答、计算、证明、应用题（数学）；其他学科对应其题型。
4. **成题**：按下方「题目输出格式」，每题标注难度与知识点。
5. **配解析**：每题给出答案 + 解题思路 + 易错点（供 A6 批改参考，也给学生订正用）。

## 二、变式规则（数学示范）

对原题做可控变异，保持考查点不变：

| 变式手法 | 说明 | 示例（一次函数 y=2x+1 过点(1,3)） |
| --- | --- | --- |
| 参数替换 | 改数字/字母 | 改 k 或点坐标 |
| 情景改编 | 换现实场景 | 速度-时间改为费用-月份 |
| 逆向设问 | 已知结果求条件 | 已知过点求解析式 |
| 条件增减 | 加减一个条件 | 增加"且与另一线平行" |
| 结论深化 | 由求值改为判断/证明 | 求交点改为判断位置关系 |

> 每次变式保留**考查点**不变，只改**表层**；避免无意义改动导致考点漂移。

## 三、难度分层定义

- **L1 基础**：一个知识点的直接应用，无陷阱。
- **L2 常规**：标准题型，需 1-2 步推理。
- **L3 变式**：条件/情境变异或逆向，需灵活迁移。
- **L4 综合**：多知识点串联或开放设问。

## 四、题目输出格式

```
【题型】单选 / 计算 / …
【难度】L1–L4
【知识点】<名称>
【题干】…
【选项】(选做题)
【答案】…
【解析】思路 + 关键步骤 + 易错点
```

## 五、组卷与分层作业

- 分层作业按学生画像（student-profile 的 proficiency/zpd）配比：ZPD 内多练、已掌握少量巩固、过难暂不安排。
- 考试卷：注明题量、分值、时间分配。
