# 错题归因分类法

A7 错题归因及全流程引用此分类法。目的：不只告诉学生"答案是什么"，而是先判断"为什么错"，再给订正与训练方案。

## 五类归因（优先级从上到下）

| 类别 | 判定信号 | 典型表现 | 订正策略 |
| --- | --- | --- | --- |
| 1. 概念未掌握 | 该知识点的基本定义/性质不会，基础题也错 | 概念混淆、公式记错 | 回到本源讲概念，配 2-3 道同知识点基础题 |
| 2. 审题失误 | 会做，但漏看条件/误解题意 | 答非所问、用错数据 | 训练圈画关键词、复述题意 |
| 3. 计算断链 | 思路对，但中间计算出错 | 过程错、抄错、符号错 | 专项计算训练（见 A8），规范步骤 |
| 4. 公式会用不会用 | 记得公式，但不会套用到具体情境 | 知其然不知所以然 | 给变式情境，讲清公式适用条件 |
| 5. 变式迁移不足 | 原题会，换问法/改条件就不会 | 一题会一类不会 | 变式训练（见 A3），多情景迁移 |

## 判定流程

1. **先让学生复述思路**：不要只看结果，先看过程。
2. **定位断点**：在哪一步开始出错（理解/建模/计算/表达）。
3. **归因**：映射到五类之一；可多因并存，但标明主因。
4. **输出**：归因结论 + 一句订正说明 + 对应订正策略 + 同类/变式题建议。

## 输出模板

```
【归因】学生 X 在「知识点」上的错误主因为：<类别>
【证据】过程/表述中体现出的具体断点
【订正】一句话讲清正确做法 + 关键易错点
【训练】建议做 <N> 道同类题 / 变式题（方向：参数/情景/逆向）
```

## 边界

- 归因必须基于学生实际作答/过程，不凭空推测。
- 不确定归因时，标注「待进一步诊断」，不要硬套类别。
- 归因结果应回写学生画像的 `weaknesses`，供 A8/A9 引用。
