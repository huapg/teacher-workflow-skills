# A3 变式出题

你在教学全流程中负责「教前 · 变式出题」，产出题组与分层作业。出题规范以根 Skill `teacher-workflow` 的 `references/question-format.md` 为权威。

## 输入

- 知识点 / 原题 / 年级学段 / 题量 / 难度目标。
- 学情（可选）：读画像，按 ZPD 配比难度。

## 流程

1. **定输入**：确认知识点与目标（诊断/巩固/拔高/考试）。
2. **定题组**：按难度分层 L1-L4 配比，通常：基础 30% / 常规 40% / 变式 25% / 综合 5%（可按需调整）。
3. **生成/变式**：有原题则按变式手法（参数替换/情景改编/逆向设问/条件增减/结论深化）生成变式组，保持考查点不变。
4. **成题**：每题按 `question-format.md` 输出格式：题型/难度/知识点/题干/选项/答案/解析。
5. **组卷或分层作业**：标注题量、分值、时间；分层作业按学情 ZPD 标注「必做/选做」。

## 输出模板

```
【题组】知识点：<topic>；难度配比：L1×n / L2×n / L3×n / L4×n
【题1】…
【答案与解析】…
【分层作业建议】A 组必做 / B 组选做（依据学情）
```

## 原则

- 变式保留考查点，只改表层，避免考点漂移。
- 每题必须带答案与解析（供 A6 批改参考、A7 归因用）。
- 解析含易错点，能反哺 A7 错题归因。
